Put it in the game

  1. Press Download .js (or Copy the file) and save it as entities/hall-thing.js
  2. Open entities/loader.js and add this line to the list, before 'core/phobia-finish.js', so the game loads the file at all: 
        'hall-thing.js',
  3. Add the id to the creature pick list - the "entities" array inside the GAME block, kept in alphabetical order - in other/level-studio.html and other/entity-studio.html, so a level can spawn it: 
        "hall-thing",
  4. Reload the game. The entity viewer and the field guide pick the creature up by themselves once the file loads; the wiring check below says whether a step is still missing.
